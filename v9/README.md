# V9 选股策略 —— 昨日强 + 今日持续（统一强度筛选）

V9 是 V8 的升级版。V8 的问题是：只要“个股自身强势”就入选，导致把“强势板块里的跟风/半路板”当成买点。V9 只在**主线板块**里筛“**昨日强、今日持续**”的龙头，今日是否涨停都展示（涨停只说明更强，买不买、怎么买由用户判断）。

筛选四问：

1. 它所在板块是不是**主线板块**（`b_strong`，V9 判定）；
2. **昨日强不强**：昨日涨幅 ≥ 7%（涨停/接近涨停）；
3. **今日是否持续**：09:35 涨幅 ≥ 4%，且是板块内今日涨幅前 5；
4. 质量护栏：热度适中（20~300）、09:35 不跳水（`delta >= -3`）、板块今早涨幅全市场前 5。

> 与旧版（分歧低吸）的区别：不再把 `chg0935 < 9.5`（涨停排除）和 `rankPd1 <= 5`（昨日板块内前 5）当硬门槛。昨日涨停但板块内只排第 6~N、今天直接一字/封板的强票同样入选，按强度（score）排序。页面状态列：未封板 = “可买”，已封板/涨停 = “观望”（排队或等炸板回封）。

## 硬条件（`v9/js/strategy-v9.js` 中的 V9_CONFIG）

| 条件 | 阈值 | 含义 |
|---|---|---|
| blockStrong | true | 所在板块为主线板块（见下） |
| pd1Chg | >= 7% | 昨日强（涨停/接近涨停） |
| chg0935 | >= 4%（无上限） | 今日持续走强，涨停也接受 |
| rank0935 | <= 5 | 板块内今日涨幅前 5（今日领涨/持续） |
| delta = 09:35-09:33 | >= -3 | 高开不跳水 |
| heat | 20~300 | 热度适中 |
| blockRank0935 | <= 5 | 板块今早涨幅全市场排名前 5（主线） |
| nStrongBlocks | 默认放宽 | 情绪过热刹车（可设 <=8 变严格） |
| marketOk（可选门控） | 上证 > MA20 | 大盘环境过滤 |

### Block 主线判定（`v9/js/strategy.js` 的 evaluateBlockStrongV9）

1. **趋势确认**：板块指数站上 21 日线，且 5 日线向上（过滤超跌反弹“假主线”）；
2. **今日领涨**：板块 09:35 涨幅全市场排名前 5；
3. **近期强势**：板块昨日上涨；
4. **赚钱效应**：板块内有涨停龙头。

## 运行

```powershell
# 回测 + 历史龙头验证
node v9/backtest.js

# Block 历史用例回归
node test-block-v9.js

# 如需从 v8/cache 重新构建数据集（会重新抓 K 线，较慢）
node v9/build-dataset.js
node v9/backtest.js
```

浏览器端：`evaluateStockV9(item, dates, ctx)` 返回 `{ isHit, isBuy, isBoard, score, checks, tags }`。页面“强势”展示 `isHit` 的票；`isBuy` = 未封板可市价买，`isBoard` = 已封板（观望/排队）。

## 说明与风险

- 统一筛选把“昨日涨停但昨日非板块前 5”的一字/连板票也纳入（标签会标注“昨日非前5”），这类票次日波动大，必须严格止损。
- 已封板（涨停）标的当日买不进，需排队打板或等炸板回封，不要在涨停板上盲目追高。
- 数据样本有限；参数按当前样本调优，换市场阶段需重新回测。
